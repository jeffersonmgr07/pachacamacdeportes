# Campeonato Clausura de Menores 2026

Esta carpeta contiene el frontend independiente del Clausura.

Antes de publicar, abre `assets/clausura-config.js` y pega la URL de la implementación pública del Apps Script:

```js
API_URL: "https://script.google.com/macros/s/XXXXX/exec"
```

El botón de pago online aparecerá únicamente cuando `ONLINE_PAYMENT_URL_TEMPLATE` esté configurado en la hoja `Config` del backend.
