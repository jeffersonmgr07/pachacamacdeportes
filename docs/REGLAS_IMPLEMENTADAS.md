# Reglas implementadas

- Categorías Sub 6, Sub 8, Sub 10, Sub 12, Sub 13 y Sub 15.
- Login por correo y clave temporal.
- Clave temporal: DNI + inicial del primer nombre + 2026.
- Máximo 15 jugadores por equipo en el panel entrenador.
- Convocatoria habilitada solo para la fecha actual configurada en `CURRENT_ROUND`.
- Fechas posteriores se muestran bloqueadas.
- Tabla de posiciones calculada en HTML leyendo resultados del fixture.
- Google Sheets es la base de datos editable.
