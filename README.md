# Corrección: Clausura 2026 usando la caja general

Este paquete conecta el Apps Script independiente del Campeonato Clausura 2026 con la caja antigua de Pacha Deportes.

## Reemplazar o agregar

### Proyecto Apps Script del Clausura
- Reemplazar `Code.gs` por `apps-script-campeonato-clausura-2026/Code.gs`.

### Proyecto Apps Script antiguo de campos y talleres
- Agregar `ClausuraBridge.gs`.
- Reemplazar `Cashier.html`.
- No reemplazar `Code.gs` ni `Workshops.gs` del sistema antiguo.

### GitHub Pages
- Reemplazar `campeonato-clausura-2026/assets/clausura-api.js`.

Lee `docs/INTEGRACION_CAJA_GENERAL_CLAUSURA_2026.md` antes de desplegar.
