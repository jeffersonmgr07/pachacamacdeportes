# Fotos de jugadores

En la versión Apps Script, las fotos deben ir en Google Drive.

Ruta recomendada en Drive:

IMG/jugadores/

Formato:

DNI.png

Ejemplo:

94768639.png
91972988.png
92523349.png

Luego pega el ID de la carpeta en la hoja Config, campo:

PLAYER_PHOTOS_FOLDER_ID

También puedes escribir una URL pública manualmente en la columna photoUrl de la hoja Jugadores.
